# Gli altri agenti

Questo kit contiene **due** dei nove agenti del sistema completo: il ramo ricerca.

| Agente | Ruolo | Nel kit |
|---|---|---|
| **SA1** competitor analysis | spy Meta + Google, messaging matrix, spazi liberi | ✅ incluso |
| **SA2** market research | voce del cliente, JTBD, forze, profili | ✅ incluso |
| SA3 financial performance | MER, ROAS, CPA, ripartizione budget | template vuoto |
| SA4 strategist | posizionamento, tono di voce, architettura campagna | template vuoto |
| SA5 creative concepts | angoli e concept dalle prove | template vuoto |
| SA6 asset production | statiche, video, UGC, product shot | template vuoto |
| SA7 ad copywriter | copy Meta e Google | template vuoto |
| SA8 analytics | report ricorrenti sugli account | template vuoto |
| SA9 CRM lifecycle | segmenti, RFM, email | template vuoto |

Per aggiungerne uno: copia `agent.template.md`, mettilo in `.claude/agents/` con un nome
tuo, compila frontmatter e SOP. Claude Code lo trova da solo e lo invoca via Task tool.
